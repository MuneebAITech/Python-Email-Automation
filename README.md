\# Email Automation Tool



A Python-based Email Automation Tool with GUI support.



\## Features



\* Send bulk emails from Excel files

\* Personalized emails using Jinja2 templates

\* Email validation before sending

\* Dynamic email subjects

\* Dynamic PDF attachments

\* Success and failure logging

\* Email summary report generation

\* GUI application using CustomTkinter



\## Technologies Used



\* Python

\* Pandas

\* Jinja2

\* CustomTkinter

\* SMTP

\* Email Validator



\## Project Structure



```text

attachments/

inputs/

outputs/

templates/

src/

```



\## How to Run



1\. Install dependencies



```bash

pip install -r requirements.txt

```



2\. Configure `.env` file



```text

EMAIL\_ADDRESS=your\_email@gmail.com

EMAIL\_PASSWORD=your\_app\_password

```



3\. Run the application



```bash

python src/gui.py

```
